# Contributing to HolyArrs

Thanks for wanting to help. Here's how to make it count.

## Found a bug?

Open an issue with the **Bug report** template. Steps to reproduce, your version and how you run it (Docker, NAS, etc.) save a lot of back and forth.

## Have an idea?

Check the [roadmap](https://holyarrs.com/roadmap/) first. If it's there, vote for it. If it isn't, open an issue with the **Feature request** template, or bring it up on [r/HolyArrs](https://reddit.com/r/HolyArrs).

## Want to send code?

Open an issue first and say what you'd like to change. That way nobody spends a weekend on a pull request that clashes with something already in progress.

## Security problems

Please don't post them publicly. See [SECURITY.md](SECURITY.md).

## Be decent

Be kind, assume good faith, and keep it about the work.
